# OUTPUT-CARDS · 结构化输出规范

> 本文件定义东南大学校园生活指南（seu-campus-guide）回答时的**统一输出格式**。
> 核心原则：**先结论、后卡片、附出处、标时效**。用结构化卡片代替大段文字。

---

## 零、总则（每次回答前默念）

1. **先给一句话结论**（Direct Answer）：用 1–2 句直接回答用户问题。
2. **再给结构化卡片**：按问题类型选下表对应卡片，模板见下。
3. **卡片后标注出处**：末尾一行 `> 📚 出处：` 指向 references 文档名或原始 PDF 页 / 牌区图号。
4. **时效提醒**：时间、电话、校车等如可能调整，加一行 `> ⚠️ 以最新通知为准`。
5. **一个回答 ≤ 1–2 张卡**，避免卡片轰炸；简短问答（一句话能答完）不必用卡。

---

## §A 时间-地点链条卡（Time × Place Chain）

**适用**：用户想知道"什么时间、在哪里、做什么"——报到当天安排、去机场/南站要多久、一个普通工作日的动线、九龙湖到四牌楼通勤。

### 模板 A1：横向时间链条

```
🕐 **{日期/时段} · {校区} 动线**

| ⏱ 时间 | 📍 地点 | 📋 事项 | 💡 备注 |
|---|---|---|---|
| {07:00} | {沙塘园食堂} | {早餐开始} | {至 09:00} |
| {08:00} | {图书馆} | {开馆，可自习} | {22:00 闭馆} |
```

### 模板 A2：纵向行程链（带每段耗时）

```
🚶 **{起点} → {终点} 最短耗时**

| 步骤 | 方式 | 耗时 |
|---|---|---|
| {宿舍} → {浮桥站} | 步行 | 5 min |
| {浮桥站} → {南京南站} | 地铁 3 号线 | 20 min |
| **合计** | | **~40 min**（含候车）|
```

### ✅ 真实示例（到南京南站）

```
🚶 **四牌楼宿舍 → 南京南站（最短 ~40 min）**

| 步骤 | 方式 | 耗时 |
|---|---|---|
| 宿舍区 → 浮桥/鸡鸣寺站 | 步行 | 5–10 min |
| 候车 | — | 0–6 min |
| 3 号线 → 南京南站 | 地铁 | 20–22 min |
| 出站进站 | 步行 | 3–10 min |

> 📚 出处：05-校园交通.md（牌区指南 2026 图 11）
```

## §B 流程步骤卡（How-To）

**适用**：报修、补办校园卡、医保注册、借书、预约场馆等"先做 A 再做 B"的问题。

### 模板 B

```
✅ **{要办的事}，{N} 步搞定**

**准备**：{材料 / 前提条件，如"卡内余额 ≥5 元 + 身份证"}

1. **{第一步}** — {怎么做}（{在哪/用什么}）
2. **{第二步}** — {怎么做}
3. …

> 🛟 卡壳了：{兜底电话 / 现场人工台位置}
> 📚 出处：{来源}
```

### ✅ 真实示例（补办校园卡）

```
✅ **校园卡挂失补办，3 步搞定**

**准备**：身份证 + 卡内余额 ≥ 5 元

1. **挂失** — 数智东南 App「校园卡」冻结（防盗刷）
2. **找自助补卡机** — 中山院 1F 北门厅 或 群贤楼 1F
3. **刷卡补办** — 放身份证 → 自动出卡（原余额转入）

> 🛟 卡壳了：群贤楼 1F 服务台现场人工处理
> 📚 出处：11-校园卡与信息化.md
```

**适用**："图书馆里有什么""中山院有没有饮水机""教学楼在哪上晚自习"——**地点维度**的设施罗列。

### 模板 C

```
| 设施 | 位置 | 备注 |
|---|---|---|
| {卫生间} | {西侧楼梯旁} | — |
| {饮水机} | {2F 走廊} | 冷热直饮 |

> 📚 出处：{来源}
```

### ✅ 真实示例（礼东/礼西 卫生间）

```
📍 **礼东 / 礼西 · 卫生间速查**（四牌楼校区）

| 建筑 | 最近卫生间 | 备注 |
|---|---|---|
| 礼东 | 北侧户外独立建筑 | 需从 1 楼离开礼东 |
| 礼西 | 测振中心 | 楼内无卫生间 |

> 📚 出处：08-教学楼与教室.md（牌区指南 2026 图 02）
```

## §E 校区对照卡（Campus Compare）

**适用**："九龙湖和四牌楼食堂几点开""丁家桥有没有图书馆"——**同项服务跨校区对比**。

### 模板 E

```
🔁 **{服务项目} · 三校区对照**

| 维度 | 四牌楼 | 九龙湖 | 丁家桥 |
|---|---|---|---|
| {食堂} | {沙塘园/香园/莘园} | {桃园/梅园…} | {医林} |
| {洗浴时间} | {7:00–次日1:00} | {24h} | {7:00–次日1:00} |

> 📚 出处：{来源}
```

> ⚠️ 回答前先确认用户在哪个校区，默认给四牌楼 + 该生所在校区即可，不必总铺三列。

## 二、组合示例（问答演示）

> 用户："新生报到那天什么流程？"

```
🕐 **报到日（2026.9.15 前后）· 动线**

| ⏱ 时间 | 📍 地点 | 📋 事项 |
|---|---|---|
| 入校 | 各宿舍区迎新工作台 | 核对名单、领住宿卡 |
| 随即 | 宿舍楼 | 填住宿卡（备 2 寸照 1 张）、领钥匙空调遥控器 |
| 报到期 | 迎新系统 yingxin.seu.edu.cn | 医保注册、上传照片缴费 |

**必带**：录取通知书、身份证、2 寸照片 ≥1 张、一卡通

> 📚 出处：02-入学迎新.md / 03-住宿生活.md（后勤指南 P1）
> ⚠️ 具体日期以录取通知书/辅导员通知为准
```

## 三、反面示例（不要这样答）

❌ 没有结论，直接甩表格  
❌ 用 5 张卡堆砌一个简单问题  
❌ 数据无出处、无"以通知为准"  
❌ 跨校区信息不标明是哪个校区
