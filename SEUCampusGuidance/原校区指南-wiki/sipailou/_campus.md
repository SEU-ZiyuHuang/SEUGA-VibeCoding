# 四牌楼校区

## 时效提醒

本文由《东南大学新生实用信息简明指南·四牌楼篇》（2025.08）11 张图片整理而成，适合直接阅读，也可作为校区指南 Agent 的基础知识源。
**时效提醒：**营业时间、门禁权限、公交线路、办公室位置、收费方式、网址和 App 入口可能调整。回答用户时应说明“以下信息来自 2025.08 版指南”，涉及当天是否开放、当前班次、费用或紧急就医时，应建议用户通过学校官网、现场公告或地图/公交 App 再确认。

## 回答规则

将本文接入校区指南 Agent 时，建议遵循以下回答规则：

1. **先识别区域。**用户说“宿舍”“食堂”“快递”时，优先追问其住宿区或楼栋：校西、沙塘园、成园或文昌。
2. **区分稳定知识和时效信息。**空间位置、楼栋关系相对稳定；营业时间、门禁、公交、收费、App 入口均属于时效信息。
3. **不得把 2025 版数据说成实时结果。**建议使用“2025.08 版指南显示……”等表述。
4. **差异项并列呈现。**食堂营业时间若遇 P02 与分区页不一致，应回答“约 06:30/06:40 开始，以现场为准”，不要擅自选一个。
5. **紧急问题优先安全。**涉及受伤、急病、火灾等，应先建议联系 120/119、校医院或校园安保，再提供位置参考。
6. **路线只作参考。**公交线路与首末班时间应提示用户用实时地图或官方运营信息复核。
7. **保留来源页码。**知识分块时可将 `[源图 Pxx]` 作为元数据，方便回看原图。
