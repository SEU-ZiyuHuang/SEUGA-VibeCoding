# 体育、门禁与停车指南

> 适用范围：丁家桥；具体服务以正文人群为准。
> 来源：25版《新生实用信息简明指南》；源图 P03, P04。
> 状态：资料整理；未全面实时核验；整理日期：2026-09-05。

> 本页保留原指南版本，属于历史参考；未在本次逐条核验，不表示当前营业、收费、门禁或班次。

### 6.1 跑操

| 项目 | 原指南信息 |
| --- | --- |
| 平台 | 小程序“东南大学体育管理”，跑步前后拍照打卡 |
| 地点 | 丁家桥校区体育场 |
| 时间 | 每天 `08:00—22:00`；每学期截止日期在第16周以前 |
| 距离 | 一次 `1.2 km`；跑道单圈 `400 m` |

### 6.2 宿舍门禁

- `24 h` 刷卡或刷脸通行。
- 仅本宿舍住户有门禁权限。[源图 P04]

### 6.3 停车与电单车充电

| 类别 | 原指南规则/位置 |
| --- | --- |
| 机动车 | 通常不允许教职工以外人员驾驶机动车进入校园。[源图 P04] |
| 非机动车停车 | 各宿舍楼下、基二楼北、综合楼北。[源图 P04] |
| 电单车充电和停放 | 求恩1/5舍外、基一楼、基二楼北。[源图 P04] |
