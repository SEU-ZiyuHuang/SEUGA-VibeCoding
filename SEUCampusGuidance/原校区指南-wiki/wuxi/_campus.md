# 无锡校区

## 时效提醒

本文由《东南大学新生实用信息简明指南·无锡篇》（原发布标题称“给新生的25版东大无锡校区指南”）8 张图片整理而成，适合直接阅读，也可作为校区指南 Agent 的基础知识源。
**时效提醒：**原图中的开放时间、营业时间、班次、票价、地铁首末班、公交线路、商户、联系电话、QQ群、预约入口和校内规则均可能调整。回答用户时应说明“以下信息来自2025版指南”；涉及当天开放、当前班次、费用、门禁、医保或紧急事项时，应建议通过学校官方渠道、运营方 App、现场公告或地图导航实时复核。
**事实边界：**本文只整理原图可支持的内容，未进行实时外部核验。地图仅用于表达相对位置，不代表精确比例、坐标或无障碍路线。

## 回答规则

将本文接入校区指南 Agent 时，遵循以下回答规则：

1. 回答到地铁站的路线前，先确认用户从北门、南门还是东门出发，以及步行、自行车、电动车、公交或无人小巴的偏好。
2. 回答自习、研讨室、考研教室或场馆问题前，先确认使用日期、用户身份/年级、具体空间和是否已经有预约权限。
3. 回答宿舍问题前，先确认榴园具体楼栋和楼层；不要把1/2舍二人间规则与3—7舍三/四人间规则混用。
4. 回答一卡通、快递、食堂、医务室、地铁、公交、无人小巴、商户或景区问题时，应明确说明数据来自2025版静态指南，并建议复核当前状态。
5. 不得把原图中的估算距离、时间或票价说成实时导航结果。
6. 对P07中的“未名路/棵城路”站名差异，应提示用户使用实时公交平台核对，不能自行替换。
7. 涉及医疗、火灾、治安、严重受伤或其他紧急情况时，安全优先：先建议联系官方紧急渠道、校方值班人员或现场人员，再提供静态点位信息。
