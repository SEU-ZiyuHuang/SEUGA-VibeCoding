# 体育场馆与跑操指南

> 适用范围：九龙湖；具体服务以正文人群为准。
> 来源：2025.09 版《新生实用信息简明指南》；源图 P08。
> 状态：资料整理；未全面实时核验；整理日期：2026-09-05。

> 本页保留原指南版本，属于历史参考；未在本次逐条核验，不表示当前营业、收费、门禁或班次。

### 7.1 跑操

1. 使用小程序 **“东南大学体育管理”**，跑步前后拍照打卡。
2. 地点：桃园、梅园或橘园田径场。
3. 时间：每天 **08:00—22:00**；每学期截止日期原指南称在第 16 周以前，具体看当学期通知。
4. 一次要求 **1.2 km**；跑道单圈约 **400 m**。[源图 P08]

### 7.2 体育场馆预约

- 入口：**数智东南 App / 信息门户网站 → 场馆预约**。
- 每日 **12:30** 放出三天后的场地。
- 预约后需至少提前 **2 小时**取消。
- 签到窗口：预约开始前 30 min 至开始后 15 min。
- 未取消且未签到者将被列入黑名单，原指南称 **3 日内不得重新预约**。
- 羽毛球场地原指南称每人每日只可预约一次。[源图 P08]

### 7.3 游泳馆

#### 学期内开放安排

| 时段 | 开放情况 |
| --- | --- |
| 12:00—13:30 | 开放 |
| 14:30—15:30 | 仅周三、周六、周日 |
| 16:00—17:30 | 仅周六、周日 |
| 18:00—19:30 | 开放 |
| 20:00—21:30 | 开放 |

- 比赛期间暂停开放，节假日场次可能缩减。
- 价格：学生 `10 元/次、750 元/年`；教师 `20 元/次、1500 元/年`；校外 `30 元/次、3000 元/年`。
- 次卡/年卡入场需刷卡缴费并签到。
- 年卡办理：原指南称每周一至周四 **09:00—11:30、14:00—16:00** 前往游泳馆 208 室。
- 入场需办理健康证；持一年内有效体检报告者可能免做部分检查。九龙湖校区学生可到校医院完成体检，并与游泳健康检查相关手续一并办理。[源图 P08]

> 游泳馆开放日、价格、办卡时间与健康证明要求均属高时效信息，使用前必须复核。

### 7.4 体育设施分布

- 桃园片区：桃园田径场、篮球场、风雨篮球场、排球场、射箭场、轮滑场地、看台、游泳馆、体育馆。
- 体育馆内原图标有篮球、羽毛球、跆拳道、健身操、健身房、乒乓球等空间。
- 梅园片区：梅园田径场、网球场。
- 橘园片区：橘园田径场及篮球、排球、足球等设施。[源图 P08]

### 7.5 体育系联系方式

- 副主任办公室：体育馆主馆 108；`025-52090821`、`025-52090822`。
- 教务办公室：体育馆主馆 102；`025-52090820`。[源图 P08]
