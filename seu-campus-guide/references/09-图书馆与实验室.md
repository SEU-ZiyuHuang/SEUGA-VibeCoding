## 二、借阅规则（2026 修订）

### 2.1 借书基本规则

| 项 | 内容 |
|---|---|
| 借书凭证 | 本人校园卡（人脸识别），各校区通借；**不可代借、冒借** |
| **借书册数** | 教职工 / 研究生 **100 册**（含外文 5 册）；本科生 **100 册**（含外文 2 册） |
| **借阅期限** | **30 天** |
| 借前检查 | 自行检查书中有无污损缺页，发现主动告知工作人员 |
| 逾期 | 按《违章处理规则》收资料逾期占用费 |

### 2.2 假期/实习顺延

- **寒暑假到期**：假期结束 7 日内归还，不作逾期
- **法定节假日到期**：节后次日归还
- **外出实习到期**：实习前班级统一凭院系证明办延期；返校后 7 日内归还

### 2.3 续借

- 每本书可续借 **5 次**
- 在到期前 **10 日内**登录"我的图书馆"自助办理
- **每次续借 30 天**；已被他人预约的书不可续借

### 2.4 预约

- 图书已借完时：主页"我的图书馆"自助预约 → 次日起查是否到馆
- 预约书保留 **7 天**，及时到所在馆借书处办理

### 2.5 不外借资料

特藏阅览室、校友捐赠室、特殊资料阅览室、报刊与大套书阅览室 → **仅提供阅览/复印**，不外借

### 2.6 权限终止条件

① 借阅逾期 ② 逾期占用费超限额 ③ 其他违章

> 出处：lib.seu.edu.cn《图书借阅规则（2026 修订）》（fid=227&id=1742）

## 三、跨校区委托借还

| 项 | 说明 |
|---|---|
| 服务对象 | 持校园卡且已注册的所有读者 |
| 服务范围 | 本校各校区图书馆 |
| 办理方式 | 主页登录"我的图书馆"自助办委托 |
| 委托条件 | 委托图书须**本校区无馆藏或已借完**，且他校区呈"可借/在馆" |
| 册数 | 委托册数 + 在借册数 ≤ 最大可借册数 |
| 有效期 | 委托申请之日起 **7 日** |
| 到书借阅 | 到书后 **15 日内**到委托台办理，逾期送回原馆并记违章 1 次（累计 3 次暂停委托权限一学年） |
| **委托还书** | 归还他校区图书需**本校区人工服务台**办理（自助设备不可用） |

## 四、自习与座位

### 4.1 座位预约（四牌楼 / 丁家桥）

> ⚠️ **四牌楼校区图书馆和丁家桥校区图书馆大部分空间实行预约制**（先约先得）

三步预约：
1. 关注公众号**"东南大学图书馆"** → 点击"**座位预约**"（首次需注册）
2. 挑选位置（靠窗 / 靠墙 / 近插座）预约
3. 约定时间到馆，**刷卡或扫码签到**入座

⚠️ 预约提醒：
- 临时来不了**提前取消**，否则记违规（影响后续预约资格）
- 签到有限时，别踩点
- 离馆不再使用**释放座位**

### 4.2 自助 / 研讨空间预约

- **李文正图书馆（九龙湖）**：首页"空间预约"或**扫码研修间门牌二维码**（需连校园网）
- 预约初始账号密码：一卡通号
- 开放 8:00 – 22:00；线上可提前 **1 天**预约
- 多人间有最低人数要求（未达视为违约）；两次预约不到 = 恶意预约（取消 1 个月权限）
- 预约后须在开始时刻前 10 min – 后 30 min 刷卡进入，否则记违约
- 四牌楼 / 丁家桥研讨间预约后请馆员开门

各校区咨询电话：九龙湖 **52090335** / 四牌楼 **83792630** / 丁家桥 **83272462**

### 4.3 自修室规则

| 馆 | 自修室 | 时间 |
|---|---|---|
| 李文正馆 | B107 | 8:00 – 23:00（全年基本不关） |
| 李文正馆 | A500 | 8:00 – 22:00 |
| 四牌楼馆 | 105 | 8:00 – 22:00 |
| 丁家桥馆 | 101 | 8:00 – 22:00 |

- 自修室保持安静，禁止进食，禁止占座，闭馆后不留个人物品

### 4.4 读者物品滞留规则（2024）

- 图书馆不负责保管读者个人物品；"物随人走，人离位清"
- 禁止占座、藏匿私人物品；禁止携带无盖瓶饮料、整理箱等
- **每晚闭馆清理滞留物品**；占座用饮料/食物/纸箱直接作"无主废弃物"丢弃
- 暂存点物品**每月清理一次**，逾期未取视为弃物由物业处理

## 七、入馆须知与管理规则

### 7.1 入馆方式

- 凭本人校园卡**刷卡（人脸识别）**进出馆
- 未带卡可凭有效身份证件登记入馆
- **严禁使用他人证件入馆**

### 7.2 公共场所规范（要点）

1. 仪表整洁；按区域保持安静或小声交谈
2. 禁止在阅览区 / 书库**用餐、吃零食、喝无盖有色饮料**
3. 校园卡不得转借；请勿携未办理借阅手续的图书出馆；离校前还清图书
4. 不写划书刊设备、**严禁占座**、离馆带清个人物品
5. 严禁携带易燃易爆品、馆内吸烟明火、触碰消防按钮监控
6. 合理使用电子资源（见《关于电子资源版权的公告》）
7. 违者按《图书馆违章处理工作规则》处理（联系电话 52090328）

### 7.3 新书展示室（李文正 A100）管理

- 8:00 – 22:00；支持普通阅览 + 轻声讨论（会办文献展览）
- 新书上架可直接借阅；禁止用餐 / 无盖有色饮品
- 自助设备异常咨询工作人员
