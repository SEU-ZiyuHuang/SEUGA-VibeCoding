### 1.1 校区分区

四牌楼校区可按生活与教学功能大致分为：

- **主教学区：**校区中北部，主要教学楼、图书馆、体育馆、礼堂和行政办事点集中于此。
- **校西住宿区：**校区西侧，包含群英楼、荟萃楼、学府二舍及香园食堂。
- **沙塘园/成园住宿区：**校区南侧、老虎桥以南一带，邻近沙塘园食堂和校医院。
- **文昌住宿区：**成贤街东侧，包含文昌 6—16 舍及莘园食堂。

校区主要出入口包括南门、东门、西门，以及通往各住宿区的门禁入口。主要道路和周边街巷包括北京东路、成贤街、四牌楼、进香河路、学府路、太平北路、文昌桥、石婆婆巷、蔡巷等。[源图 P02]

### 1.2 常用教学楼定位

教学楼通常开放 **07:00—22:00**。[源图 P02]

| 地点 | 定位提示 |
| --- | --- |
| 五四楼 | 从南门进入后位于左侧/西侧 |
| 中山院 | 从南门进入后位于右侧/东侧 |
| 东南院 | 校区东南角、中山院东侧 |
| 礼东 | 大礼堂东翼、中央大道尽头 |
| 礼西 | 大礼堂西翼、中央大道尽头 |
| 图书馆 | 中央大道西侧，正对百年鼎草坪；开放时间总览标为 08:00—22:00 |
| 逸夫建筑馆 | 校区西北侧，近西门；研究生院多个办公室设于此 |
| 微波楼 | 东门北侧；教务处、财务处等办事点所在楼宇 |
| 体育馆/体育场 | 主教学区西北部 |
| 校东（小营）体育场 | 文昌住宿区南侧 |
