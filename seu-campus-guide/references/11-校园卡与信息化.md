## 一、校园卡（一卡通）

### 1.1 校园卡功能

- 食堂就餐、超市购物、浴室洗浴刷卡
- 图书馆借书、校门/图书馆/宿舍进出
- 考试 / 报到身份凭证

### 1.2 消费支付方式（六种）

| # | 支付方式 | 说明 |
|---|---|---|
| 1 | 校园卡刷卡 | 实体卡 |
| 2 | 人脸支付 | 数智东南 App「**人脸采集**」开通刷脸支付 |
| 3 | NFC 支付 | 手机 NFC |
| 4 | 微信支付 | 绑定校园卡 |
| 5 | 支付宝支付 | 绑定校园卡 |
| 6 | 付款码支付 | App / 微信 / 支付宝付款码 |

> ⚠️ **挂失实体卡后**，仍可通过刷脸、NFC、微信 / 支付宝付款码等方式消费（挂失仅限实体卡）。

### 1.3 充值渠道

**方式一：数智东南 App 充值（推荐）**
1. 输入姓名 + 查询密码（默认身份证后六位数字）→ 验证
2. 开通电子钱包：建行卡用户选"建行卡快速绑定"，其他银行选"银行卡绑定"
   - 例（中行卡）：输入银行卡号 → 下一步 → 选证件类型 → 上传证件照片 → 输入手机号 → 获取短信验证码 → 激活成功
3. 返回校园卡应用首页 → 充值 → 输入金额 → 选支付方式 → 卡片充值
- 支持**银行卡充值、微信充值、支付宝充值**

**方式二："东大财务"微信公众号充值**
- 暂无银行卡的新生可选此方式，使用微信钱包充值校园卡

**其他（牌区指南 图 04）**：
- 中国银行 App：乐知校园 → 充值中心（01:00–23:00）
- 圈存机：食堂 / 群贤楼 / 校西综合楼 2 楼 / 校医院

### 1.4 挂失 / 解挂

- 数智东南 App「校园卡」应用 或 **实体圈存机** 均可挂失（防盗刷）
- 找回已挂失卡 → 同一入口解挂
- 挂失后仍可用刷脸 / NFC / 付款码消费

### 1.5 补办

- **携带本人身份证**，前往校内**自助补卡机**办理新卡

| 自助补卡机位置 | 说明 |
|---|---|
| **中山院 1 楼**（北门厅） | 四牌楼 |
| **群贤楼 1 楼** | 四牌楼 |

### 1.6 校园卡服务台（人工）

| 校区 | 位置 | 服务时间 |
|---|---|---|
| **九龙湖校区** | 教一 **101A** | 每周一 / 三 / 四 8:30–12:00、13:30–17:00 |
| **四牌楼校区** | 校西进香河校区**综合楼 2 楼 210** | 每周二 / 五 8:00–12:00、14:00–18:00 |

可办理：重置密码、补换卡片、挂失与解挂、卡片校正等

### 1.7 NFC 联名卡

- 已推出**与南京市民卡 NFC 联名卡**：手机即可完成校内消费 + 公共交通支付
- **无开卡费**，享优惠换乘政策

## 二、校园网（SEU-WLAN）

### 2.1 基本说明

- **校园网无需注册，登录即用**：一卡通号以"2"开头的全日制在校生自动集成注册，**无需自行申请**
- 初始账号 = 一卡通号；密码 = 身份证后六位

### 2.2 两个无线网

| 网络 | 说明 | 覆盖 |
|---|---|---|
| **SEU-WLAN** | 校园官方无线网：打开浏览器访问任一校外 http 网页自动弹认证页，输入统一身份认证账号密码即可上网 | 校园范围内 |
| **SEU-ISP** | 移动 / 联通 / 电信三大运营商共建的商业网 | **学生宿舍区域** |

- SEU-WLAN 未自动弹认证页时，浏览器输入 **w.seu.edu.cn** 后认证
- ⚠️ SEU-ISP 可访问外网资源，但**不支持校园内网应用**（正版软件下载、东大云盘等），需自行向运营商办理

### 2.3 有线网接入

- 接寝室网线口即可（认证方式同 SEU-WLAN）

### 2.4 校园网充值

| 方式 | 路径 |
|---|---|
| 数智东南 App | 工作台 → 网络服务 → **网费账户充值** |
| 官网 | nic.seu.edu.cn → 推荐服务 → 校园网服务 → 校园网自助服务系统 → 网费账户充值 |

### 2.5 套餐变更（次月生效）

| 方式 | 路径 |
|---|---|
| 官网 | nic.seu.edu.cn → 推荐服务 → 校园网服务 → 服务 → 预约套餐 |
| 数智东南 App | 工作台 → 网络服务 → 服务 → 预约套餐 |

> 默认资费为 A 套餐，具体标准见 nic.seu.edu.cn 公告

### 2.6 VPN / 5G 融合校园网

- **零信任 VPN**：校外访问校内网站 / 数据库使用
- **5G 融合校园网**：全国 4G / 5G 信号下**不换卡、不换号、不用 VPN**，随时随地接入校园网（相当于校园网全国覆盖）
  - 适用：手机号归属地为**南京移动或江苏联通**可免费开通
  - 开通成功享流量福利

### 2.7 修改密码

1. 已绑定手机号 → 统一身份认证页面"修改密码"，通过绑定手机修改
2. **未绑定手机号无法自行修改** → 拨打网信中心反馈电话 **83790808**

## 三、数智东南 App

### 3.1 下载途径

| 方式 | 说明 |
|---|---|
| 应用商店 | App Store / 华为应用市场 / OPPO 软件商店 / 小米商城 / vivo 应用商店搜索"数智东南" |
| 官网下载 | 浏览器输入 **app.seu.edu.cn** 选手机 / 电脑客户端 |
| 扫码 | 官方二维码 |

### 3.2 登录

- 初次登录用户均通过**统一身份认证**登录
- 登录后进入**手机号验证**环节，务必核查手机号是否正确

**手机号有误修改途径**：
- 方式一：扫码登记新号码（查询验证），2 小时左右生效（**仅适用于报到前**，入学后须通过学工系统修改）
- 方式二（入学后）：
  - 本科生：i.seu.edu.cn → 应用中心 → 基本信息
  - 研究生：i.seu.edu.cn → 应用中心 → 研究生综合管理系统 → 学籍勘误
  - 修改后需经学院审批

### 3.3 核心功能

| 模块 | 功能 |
|---|---|
| **消息沟通** | 通讯录（同学院同班级人员可见）、已读显示、聊天记录与文件**加密存储在学校服务器** |
| **办事服务** | 「**云游东南**」校园电子地图（**接驳车实时位置、充电桩空闲状态、停车位导航、AED 一键查询**）、课表查询、校园卡管理、人脸采集、报修咨询、场馆预约、教室借用、云盘、大型仪器共享等 |
| **资讯服务** | 刷码支付、教育邮箱、课程周历、校历查询等九种常用功能 |

> ⚠️ 鸿蒙用户请在**微信搜索"云游东南"**使用电子地图
