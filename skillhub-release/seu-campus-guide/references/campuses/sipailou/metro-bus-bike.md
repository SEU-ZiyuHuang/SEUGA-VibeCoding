# 四牌楼地铁、跨校区与夜间出行

> 适用范围：四牌楼出发；须明确起点和出行日期。
> 来源：东南大学地理协会《新生实用信息简明指南·四牌楼篇》2026.08；文件编号＝印刷页码＋1，印刷11；2026研究生报到须知PDF第2页。
> 状态：换乘关系已交叉核对；时长、票价和首末班不作为实时结果；整理日期：2026-09-05。

## 到地铁站

图11按起点给出静态估计：南门／沙塘园至附近地铁约600米、5分钟；东门／文昌约400米、5分钟；西门／校西约1公里、10分钟。步行估计不含等灯、绕行和门禁，不据此承诺赶车。

浮桥站为3号线，鸡鸣寺站为3／4号线换乘站。选择出口应结合宿舍区，图示出口与首末班只代表资料版本，不作为当前末班保障。

## 常用方向

| 目的地 | 参考路线 | 2026图11全程最低耗时估计 |
|---|---|---|
| 南京南站 | 前往附近合适地铁站，乘1或3号线至南京南站，再出站进铁路站 | 至少40分钟 |
| 南京站 | 乘1或3号线至南京站 | 至少20分钟 |
| 禄口机场 | 地铁至南京南站，换S1号线 | 至少80分钟 |
| 九龙湖校区 | 3号线至东大九龙湖校区站，再到校门 | 至少60分钟 |
| 丁家桥／中大医院 | 鸡鸣寺乘4号线至鼓楼换1号线到玄武门；或结合5号线青春广场等入口 | 图示至少15分钟，非可靠赶场时间 |

**玄武门是1号线站点，4号线不能直达玄武门。** 新包把图中的“4→1”换乘关系压成了“4号线→玄武门”，已纠正；[2026研究生报到须知PDF](https://yzb.seu.edu.cn/_upload/article/files/4c/b4/ae3d57374745b13970e947a506c8/a0e45ee8-7394-488d-81fa-a171030164af.pdf)第2页亦明确写乘1号线到玄武门。

## 夜间与骑行

图11列出的夜间公交候选包括往南京南站的Y16／Y8、往丁家桥方向的Y2，以及机场大巴。班次、停靠站和机场大巴首班需要查询当日运营信息；不保留85元、30元等旧打车估价作为现价。

图示各宿舍围合不允许共享单车进入；自备电单车能否进教学区和停放须服从当前校规。文昌8／9附近有地下非机动车库；文昌10／13、太平北路口和校西有充电区域，是否空闲需现场确认。

接驳车见[班次核验](../../common/shuttle-status.md)，跨校区问题还需读取目的校区交通页。
