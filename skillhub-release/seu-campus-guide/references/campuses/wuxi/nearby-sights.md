### 8.2 周边景点

| 景点 | 原指南位置/特点 | 时间或条件 |
| --- | --- | --- |
| 长广溪湿地公园 | 紧邻校区东侧 | 原图未列开放时间。[源图 P06] |
| 三国城·水浒城 | 电影取景地、5A级景点；原图提及龙王山西侧、太湖沿岸 | 原图标注全年07:30—17:30，最晚入园17:00。[源图 P06] |
| 雪浪山景区 | 滨湖区清源路南 | 薰衣草园、秋季银杏，原指南称景色很美。[源图 P06] |
| 红沙湾 | 滨湖区山水东路、太湖沿岸 | 有太湖植物园，原指南称落日很美。[源图 P06] |
| 蠡湖国家湿地公园 | 未给出更细位置 | 免费公园，适合散步、露营、野餐。[源图 P06] |
| 蠡湖中央公园 | 未给出更细位置 | 园内有雕塑、欧式建筑和文化设施。[源图 P06] |
| 鼋头渚 | 国家5A级景区 | 原指南称3月为樱花圣地，11月可观红嘴鸥。[源图 P06] |
| 贡湖湾湿地公园 | 贡湖大道和红周路交汇处南侧 | 免费公园、太湖沿线；适合散步、跑步、露营、放风筝、看日落。[源图 P06] |
| 金匮公园 | 地铁1号线市民中心2号口出 | 春季有樱花和杜鹃花，秋季有枫叶。[源图 P06] |

景区等级、营业时间、门票、预约和季节性景观均应以景区当天公告为准。
