### 5.3 校内商店与附近银行

| 类型 | 地点/信息 |
| --- | --- |
| 校内便利店 | 全家便利店、天惠超市、一鸣真鲜奶吧。[源图 P05] |
| 校内咖啡店 | 中山院一楼；原图营业时间为周一至周日08:00—17:00。[源图 P05] |
| 江大南门便利店 | 震泽路小超市，有零食、水果等。[源图 P05] |
| K-park附近 | 附近有便利店。[源图 P05] |
| 全家便利店 | 无锡太湖新城科教产业园店。[源图 P05] |
| 大型超市 | 融创茂负一层永辉超市；原指南称其为附近最大的综合性超市。[源图 P05] |
| 中国建设银行 | 无锡太湖新城科教产业园支行，长广溪地铁站1号口附近。[源图 P05] |
| 中国工商银行 | 江南大学支行，文浩科学馆北门。[源图 P05] |

商户营业状态、营业时间和银行网点均需通过地图或官方渠道复核。
