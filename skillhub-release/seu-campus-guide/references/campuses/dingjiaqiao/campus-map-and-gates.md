# 丁家桥校区校门与地图

> 适用范围：丁家桥；具体服务以正文人群为准。
> 来源：25版《新生实用信息简明指南》；源图 P02, P04, P05。
> 状态：资料整理；未全面实时核验；整理日期：2026-09-05。

> 本页保留原指南版本，属于历史参考；未在本次逐条核验，不表示当前营业、收费、门禁或班次。

### 1.1 校门与出入口

| 出入口 | 原图标注及附近点位 | 备注 |
| --- | --- | --- |
| 东1门 | 医林食堂、求恩1—5舍一带 | 地图在东1门附近标出食堂、宿舍和外卖柜。[源图 P02] |
| 东门 | 驿收发、菜鸟驿站 | 地图以红点标注“快递·驿收发”，以蓝点标注“快递·菜鸟驿站”。[源图 P02] |
| 南门 | 综合体育场南侧、童家巷方向 | 南门外可前往童家巷、狮子桥和湖南路等区域。[源图 P02、P05] |
| 操场—医院小门 | 综合体育场西南侧与东南大学附属中大医院之间 | 原指南称该小门全天开放，需刷一卡通出入；南端外卖柜也标在小门旁。[源图 P02、P05] |

### 1.2 地图中的主要校内点位

地图标出的主要建筑与空间包括：求恩1—5舍、医林食堂、博爱楼、基一楼、基二楼、图书馆、电镜楼、羽毛球馆、篮球场、文枢楼、生医实验室、综合楼、科技会堂、康健楼、蔡翘楼、公共卫生学院、综合体育场、青教公寓及停车场。[源图 P02]

| 功能 | 地图中的点位关系 |
| --- | --- |
| 教学与科研 | 基一楼、基二楼、图书馆、电镜楼、文枢楼、生医实验室、综合楼、科技会堂、康健楼、蔡翘楼等集中标在校区中部。[源图 P02] |
| 宿舍与食堂 | 求恩1—5舍与医林食堂标在东1门附近；博爱楼位于宿舍西侧。[源图 P02] |
| 体育 | 综合体育场位于校区南部，篮球场与羽毛球馆位于校区中北部。[源图 P02] |
| 快递 | 驿收发和菜鸟驿站均标在东门附近，分别位于东门北侧和南侧。[源图 P02] |
| 外卖柜 | 北端外卖柜标在宿舍、校园超市一带；南端外卖柜标在操场—医院小门旁。[源图 P02、P04] |

### 1.3 周边道路、车站与设施

地图标出了新模范马路、中央路、湖南路、童家巷、丁家桥等道路，以及新模范马路站、玄武门站、青春广场站等地铁站。周边还标出南京工业大学、中国药科大学、东南大学附属中大医院、南京市青少年宫、金茂览秀城等点位。[源图 P02]

> 地图为示意图，本文仅保留原图明确表达的相对位置和联系，不据此推导精确坐标、朝向或步行距离。
