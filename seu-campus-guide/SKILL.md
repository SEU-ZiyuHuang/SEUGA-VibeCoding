## 使用流程
1. 判断用户问题属于哪个主题 → 打开对应 references 文档（有跨主题时多开几篇）。
2. 以文档内容为准回答，注意标注校区（四牌楼/九龙湖/丁家桥 差异）。
3. **按 OUTPUT-CARDS.md 组织回答**：先一句话结论 → 再按问题类型套用对应卡片（时间-地点链条 / 流程步骤 / 地点设施 / 电话速查 / 校区对照 / 数据速览）→ 标出处 → 必要时加"以最新通知为准"。
4. 电话、时间等关键数据原样给出并加粗；提醒"以学校最新通知为准"。
5. 拿不准 → 用 README 主题矩阵导航，或诚实说明资料未覆盖，建议查官方（yingxin.seu.edu.cn 等）。

## 结构化输出规范（必读）
回答请遵循 `OUTPUT-CARDS.md`（本 skill 根目录），其中定义了 6 类卡片及其模板与真实示例：
- **A 时间-地点链条卡**：行程/流程/一天动线（如"怎么去南京南站""报到那天做什么"）
- **B 流程步骤卡**：办事步骤（报修/补卡/借书/医保）
- **C 地点-设施速查卡**：某楼/某地的设施分布（卫生间、AED、饮水机）
- **D 电话速查卡**：紧急电话、服务热线
- **E 校区对照卡**：同项服务三校区对比
- **F 数据速览卡**：时刻表、票价、营业时间等纯数据

> 记住总则：**先结论 → 再卡片 → 附出处 → 标时效**；简单问答不必强行用卡。

## 重要原则（引用与时效）
- 文档整理自 **2026 年 8 月版**官方手册与东奔南走《牌区指南 2026》，**可能滞后**于学校最新通知。
- 关键时效信息（食堂营业时间、校车时刻、图书馆延时开放、医保政策、开学/军训/考试日期）务必提醒用户以官网/辅导员最新通知为准。
- 四牌楼、九龙湖、丁家桥三校区设施与服务**差异明显**，先确认用户在哪个校区再作答。
- 文档中"出处"标注对应原始 PDF 页码或图片编号，必要时可据此追溯原始材料（东南大学新生手册2026.pdf / 后勤服务指南2026.pdf / 牌区2026指南/*.png）。
