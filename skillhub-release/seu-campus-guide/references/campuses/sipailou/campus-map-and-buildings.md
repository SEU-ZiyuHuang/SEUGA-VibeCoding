> 状态：按所列来源整理；非实时状态；整理日期：2026-09-05。

## 区域与方向

主教学区、校西、沙塘园／成园、文昌桥是不同生活区域。问路线、门禁或收件地址时需先确定区域。

| 地点 | 图示关系 |
|---|---|
| 南大门 | 中央大道南端，向北进入校园 |
| 五四楼 | 从南门进入后的左侧／西侧；不要与东北部五五楼混淆 |
| 中山院 | 从南门进入后的右侧／东侧；不是中大院 |
| 东南院 | 中山院东侧，校区东南角 |
| 礼东、礼西 | 大礼堂两翼；分别在大礼堂东侧、西侧 |
| 校图书馆 | 中央大道西侧，百年鼎附近；不是孟芳图书馆 |
| 五五楼 | 主教学区东北部；计算机实验中心参考位置 |
| 健雄院 | 大礼堂东南侧，吴健雄纪念馆所在建筑 |
| 沙塘园／成园 | 南门外住宿区域，须区分大门与楼栋权限 |
| 校西 | 主教学区西侧，经进香河路等入口进入 |
| 文昌桥 | 教学区东侧、太平北路沿线，分多个楼栋和围合 |

这些是示意关系，不是测绘坐标，也不保证最短或无障碍路线。图中的道路名、小图标若无法明确辨认，不自行推断。
