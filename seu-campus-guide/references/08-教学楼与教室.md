- **中山院**：拨打教室前方张贴电话

- **五号楼 1F 部分教室延时到 23:00 / 24:00** 关门
- 详见教室门口张贴时间

## 七、教室查借系统使用手册（完整版）

> **核心来源**：刘方《教室查借系统使用手册》（金山文档 cs9rYcWQLpaW，约 3884 字 / 22 页）  
> 系统同时支持 **PC 端**（东大信息门户）与 **移动端**（数智东南 App）

### 7.1 应用入口（官方三路径）

#### PC 端（教务处）

**教务处 jwc.seu.edu.cn** → 办事平台 → **教室查借**

#### PC 端（网上办事大厅）

**东大信息门户 i.seu.edu.cn** → 公共服务 → **教室查借**（用一卡通账号密码登录，搜索框输入"教室查借"亦可）

#### 移动端

打开**数智东南** App → **工作台** → 搜索**"教室查借"** → 点击对应图标 → 进入教室查借系统

### 7.2 通用功能

#### 登录 / 登出

- 使用**一卡通账号 + 密码**登录系统
- 点击页面**右上角个人账户图标** → 弹出"退出"按钮 → 点击即可退出登录

#### 权限

- 普通用户登录后默认可见 **2 个菜单**：
  - **查借教室**
  - **我的申请**
- 管理员 / 教师等角色另有更多菜单（详见系统权限说明）

#### 意见反馈

- 系统内可对使用问题进行反馈（具体入口在页面右下方/侧边栏）

### 7.3 查借教室

#### 搜索条件

- 进入**首页** → 设置搜索条件（校区 / 日期 / 时段 / 教学楼 / 教室类型等）
- 系统返回**符合条件的空闲教室**列表

#### 高级筛选

- 支持按**教室设施**（投影 / 空调 / 多媒体 / 桌椅类型等）进一步筛选
- 也可按**容纳人数**、**是否可借**等条件过滤

#### VR 看教室（特色功能）

- 部分教室支持 **VR 看教室**，可在申请前**在线预览教室实景**（方位、内部布局、桌椅配置等）
- 推荐先 VR 看 → 再正式申请，避免申请后才发现不合适

### 7.4 我的申请

- 入口：**我的申请**菜单
- 可查看历史申请状态（待审 / 已通过 / 已拒绝 / 已撤销 / 已过期）
- 可对**待审申请**进行撤销 / 修改

### 7.5 教室借用流程（移动端示例）

| 步骤 | 操作 |
|---|---|
| ① | 数智东南 App → 工作台 → 搜索"教室查借" |
| ② | 首页设筛选条件（校区 / 日期 / 时段）→ 查看空闲教室 |
| ③ | （可选）点 "VR 看教室" 先看教室实景 |
| ④ | 选择教室 → 点"借用" |
| ⑤ | 填写申请表**（时间 / 人数 / 用途 / 联系方式）** |
| ⑥ | 提交 → 按身份走**审批流程**（见 7.5-A，学生走辅导员→副书记→教室审核组） |
| ⑦ | 审核通过 → "我的申请" → 凭此入室 |

> ⚠️ **注意**：必须在使用前完成借用审核；**未审核通过的教室不可使用**。

### 7.5-B 线下 / 特殊借用

| 场景 | 要求 |
|---|---|
| 大规模考试、**200 人以上**大型活动、**5 间以上**大批量、**2 周以上**长时间使用 | 至少提前 **2 周** 提交专门申请报告（部门负责人签署 + 部门盖章），教务处审核调度 |
| 借用课桌椅（学生活动） | 填"教室课桌椅借用申请表"（下载专区），学院签字盖章后提前 **3 个工作日** 交教室管理与服务中心审核 |

### 7.5-C 使用要求

- 一般借用**提前 3 个工作日**在系统申请；多媒体设备有特殊需求提前联系教室管理与服务中心 / 教育技术中心
- 原则上仅供本校师生使用；教学第一、服务师生
- **先借用后使用**，不得随意占用教室；不在教室办歌舞表演、才艺展示等喧哗类活动
