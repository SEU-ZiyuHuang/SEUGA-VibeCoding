# 本科教务与资助查询

> 适用范围：本科生，按年级和专业区分。
> 来源：新包07章主题；教务处、学生处和2026本科迎新通知。
> 状态：泛化数值已剔除；不声称全面核验全部教务政策；整理日期：2026-09-05。

## 按事项查

| 问题 | 使用入口与边界 |
|---|---|
| 选课、成绩、缓考、补考、重修 | [教务处](https://jwc.seu.edu.cn/)及数智东南相应模块，时间依当前通知 |
| 修业年限、毕业学分、转专业 | 按本人入学年级、专业培养方案和当期政策，不从泛化表格推断 |
| 文教讲座与读书报告 | [文教专题](lectures.md)，仅限适用本科培养规则 |
| 奖学金、国家助学金、勤工助学 | [学生处](https://xsc.seu.edu.cn/)及本学院评审通知 |
| 国家助学贷款、绿色通道 | [2026本科迎新通知](https://yingxin.seu.edu.cn/2026/0806/c27744a578902/page.htm)与资助管理部门 |

新包中的绩点区间表、固定转专业时点及8000元／5000元奖学金标准缺乏本次适用年度核验，不作为现行定额。贷款12000元上限与2026官方迎新通知不一致，已移出正文；需要具体额度时查对应学生类型的官方通知。

研究生选课与学籍由研究生院和学院办理，本页本科培养规则不得用于研究生。
