# 住宿入住与报修

> 适用范围：南京三校区；苏州、无锡及其他校区看当地入口。
> 来源：新包03章后勤服务摘编；[2026研究生报到须知](https://yzb.seu.edu.cn/_upload/article/files/4c/b4/ae3d57374745b13970e947a506c8/a0e45ee8-7394-488d-81fa-a171030164af.pdf)。
> 状态：公寓咨询号码与官方文件交叉核对；具体响应时限不承诺；整理日期：2026-09-05。

南京三校区新生入住按分配结果到对应宿舍办理，凭录取材料及校园卡核验身份，登记、领取钥匙等。所需照片规格依宿舍当期要求，不将新包“2寸1张”推广为全校统一要求。

新包后勤指南摘编给出报修路径：数智东南 → 报修咨询服务 → 总务报修服务平台；或“东大信息化”公众号报修咨询。提交楼栋、房间、故障描述与必要照片，报修对象区分水电、家具、空调及公共设备，不自行维修危险电气设备。

2026研究生报到文件列公寓服务咨询：九龙湖025-52090478、四牌楼025-83792789、丁家桥025-83272384；这是来源文档列出的联系，不是实拨测试。苏州、无锡按当地报修入口，不能套用南京号码。

电梯困人先用轿厢报警装置、联系现场救援，不自行扒门脱困。新包电梯供应商手机号本次未独立核验，不作为唯一救援渠道。
