# 来源、版权与日期口径

本包是**不同来源、不同发布年份资料的整合**，不是统一年份的数据集。引用时按下表说明版本。

## 日期口径

三个日期不能混用，正文中分开记录：

| 口径 | 含义 |
|---|---|
| 发布／版本日期 | 原资料自身标注的年份或版本（如"2025 版""2026.08"） |
| 本次核验日期 | 本次整理时实际读取该来源的日期，均为 2026-09-05 |
| 原库核验日期 | `references/official/` 条目沿用的历史记录（2026-08-17／18），**不代表本次复核** |

"本次核验"仅指读取到了该来源页面，不代表其中每条事实在今天仍然有效。

## 五、结构化知识条目导出

保留原条目 ID、来源链接与**原库核验日期**。转换日期不是核验日期；涉及现行时间、电话、
窗口时以条目内的专项说明和对应主题页为准。读者无需运行原项目即可查阅。
