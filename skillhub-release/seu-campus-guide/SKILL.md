# 东南大学六校区校园指南

覆盖四牌楼、九龙湖、丁家桥、江北、苏州、无锡六个校区的校园生活资料。
内容按来源与发布年份分别标注，**1.2.0 是本包版本号，不代表其中每条事实都是 2026 年的**。

## 何时使用

用户问东南大学的校园生活、办事和出行时使用：报到迎新、宿舍门禁、食堂支付、校园卡、
校园网与数智东南、图书馆、教学楼自习、行政窗口、部门电话、地铁与接驳车、快递、
医疗医保、安全求助与心理、运动场馆、周边商圈、校园漫游。

不适用：招生录取分数、具体课程内容、他校信息、任何"此刻是否营业／还有几个座位／下一班几点"
这类实时状态——本包是静态资料，只能给出资料版本和查证入口。

## 查阅流程

1. 打开 [主题索引](references/index.md)，按用户问的**事情**选主题。
2. 索引只做导航，不存事实。按它指向的通用页或校区专页读正文。
3. 校区专页在 `references/campuses/（校区）/`；跨校区通用事项在 `references/common/`；
   建筑、部门、办事条目在 `references/official/`。
4. 跨校区问题分别读各自页面后再组合，不用一个校区的答案覆盖另一个。
5. 按 [OUTPUT-CARDS.md](OUTPUT-CARDS.md) 组织回答。

## 澄清规则

只有**校区、宿舍区或身份会改变答案**时才追问，其余情况直接答：

- 用户已说明校区 → 直接读该校区页，不要再问一遍。
- 未说校区且答案因校区而异（食堂、图书馆、校医院、补卡、接驳车、快递） → 先问校区。
- 答案因身份而异（本科／研究生、年级、参保地） → 先问身份。
- "图书馆""校医院""食堂"没有全校默认；兰台是九龙湖相关住宿区域，不是第七个校区。
- 入学身份与培养地点不能只按学院名称推断。

## 边界

- 静态资料。不把资料里的时间表述成"现在营业中"或"下一班"。
- 涉及时间、电话、窗口、价格、班次时，给出资料的来源与版本，并提示以当期官方通知为准。
- 遇到本包未覆盖或来源互相矛盾的问题：说明差异，给查证入口，不挑一个数字当确定答案。
  未解决的冲突集中在 [待核验事项](references/conflicts.md)。
- 紧急情况（急救、火灾、人身安全）先给行动指引，不先做校区澄清。
- 引用出处时只写你**实际读过的页面**，以及那个页面里**原文就有**的链接。
  不要凭记忆或按上一轮对话补 URL；宁可只给页名。
- 来源、版权、核验日期见 [来源说明](references/sources.md)。
