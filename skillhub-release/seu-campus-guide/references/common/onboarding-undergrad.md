# 2026级本科迎新

> 适用范围：2026级本科生。
> 来源：[本科新生入学报到须知](https://yingxin.seu.edu.cn/2026/0806/c27744a578902/page.htm)，2026-08-06发布。
> 状态：2026-09-05读取官方通知并核对关键日期及校区；整理日期：2026-09-05。

适用于2026级本科新生，不适用于研究生报到。

1. 先核对录取学院与报到校区：官方通知规定2026年8月29日报到，主要在四牌楼；东南大学—蒙纳士大学国际学院（苏州）学生在九龙湖报到，不能按学院名称直接推断去苏州。
2. 从迎新网或数智东南进入迎新服务，办理行程、住宿、组织关系等对应手续。按录取通知书与官方清单准备证件、校园卡及所需材料。
3. 学费住宿费按财务缴费平台或“东大财务”办理；困难学生按流程申请绿色通道。
4. 医保费用与保障问题看[医保专题](insurance.md)；体检按迎新预约页面确认，军训按本人学院通知。

原新包混杂的9月报到表述不用于本科新生。本次仅摘录关键校区与流程，完整材料清单请直接阅读官方通知。
