| 楼宇/片区 | 原指南标注的主要单位或功能 |

| 电子信息与土交片区 | 电子科学与工程学院、集成电路学院、信息科学与工程学院、生物科学与医学工程学院、土木工程学院、交通学院，以及土交实验楼、土交科研楼 |

| 工培中心 | 靠近西门、纪忠楼西南侧 |
| 机械与能环片区 | 机械工程学院、能源与环境学院、机械动力实验楼 |

| 常州科技楼 | 原指南标注计算机科学与工程学院、软件学院、网络空间安全学院、人工智能学院等相关空间 |
| 金智楼 | 电类实验、公共机房、网信中心、网安实验室等，详见第 3.5 节 |

| 教学楼 | J1—J8；J7 与 J8 的 1—3 层有连廊连接 |

> 楼层归属可能随学院搬迁、装修和新楼启用调整，前往办公室或实验室前建议向学院确认。[源图 P03]

### 2.2 教学楼与中心区定位

- 李文正图书馆位于校园中心。
- 润良报告厅位于图书馆东侧建筑体量内，邻近会议室。
- 教学楼 J1—J8 位于图书馆东侧；从桃园前往教学楼相对较近。
- 图书馆与教学楼之间的南北向步行联系可经大草坪周边道路或校园栈道完成。[源图 P03]
