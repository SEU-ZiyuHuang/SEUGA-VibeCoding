## 五、李文正图书馆"找座"攻略（含电源）

> 九龙湖李文正馆区划：**中厅为界，东 = A 区，西 = B 区**

| 楼层 | 区域 | 座位与电源 |
|---|---|---|
| **1F** | A100 新书展示室 | 新书架 + 多功能座位，约 1/2 桌面电源，少量墙插 |
| 1F | A101 中图 3 / B101 中图 4 | 南北两侧座位，**全部桌面电源** |
| 1F | B107 自修室 | **200+ 座位全部桌面电源**；开放时间见时段页 |
| **2F** | A201 / B201 数字学术中心 | 朝阳吧台、可移动桌椅、沙发、研讨座、蛋椅；少量地插墙插 |
| 2F | A208 中图 1 / B206 中图 2 | 座位在北侧，少量地插墙插 |
| 2F | 二楼中厅 | 东西两侧座位，**全部桌面电源** |
| **3F** | A301 艺术图书 / B301 报刊 | 南北两侧，少量墙插地插；**室外走廊一排带台灯座位，墙插充足** |
| 3F | B303 未来学习中心 | **所有座位带学习用机和桌面电源**；西侧可看九曲桥湖水 |
| **4F** | A401 工业技术图书 | 南侧座位**全部桌面电源**；室外走廊带台灯座位墙插充足 |
| 4F | B402 外文图书 | 南侧座位，少量墙插 |
| **5F** | A500 自修室 | 全阅览座位，约 1/2 桌面电源 + 少量地插；两侧为需预约研修间 |
| 5F | B502 特藏阅览室 | 民国风座位，电源充足；开放时间见现场公告 |

> ⚠️ 安全用电：离开拔插头，勿在过道拉电线；橙色预约区需空间预约系统预约；沙发区注意音量。

> 出处：《图书馆找"座"攻略》PDF（lib.seu.edu.cn 2022）
